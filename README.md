# BaseVibecode
## MOTIVO
Este repositório foi criado com o intuito de gerar um padrão de estrutura (design, segurança, etc) de projetos que a IA deve seguir quando for desenvolvendo o projeto.

## SOLUÇÃO
Um conjunto de skills para direcionar a IA ao caminho desejado.

Lista de skills:
1. [Graphify](https://github.com/Graphify-Labs/graphify)
    - Para economizar tokens da IA.
1. [Swagger](https://app.mcpmarket.com/flaviohsb06/skills/api-documentation)
    - Organizar e documentar APIs.
1. [Frontend](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md)
    - Para um frontend e UI mais organizado.
1. [test-driven-development](https://github.com/obra/superpowers/blob/main/skills/test-driven-development/SKILL.md)
    - Para realizar e automatizar testes.
1. [web security](https://github.com/Masriyan/Claude-Code-CyberSecurity-Skill/blob/main/skills/09-web-security/SKILL.md)
    - Para verificar e realizar testes de segurança na aplicação web.
1. [database-designer](https://github.com/suparno/claude-skills-sup/blob/main/engineering/database-designer/SKILL.md)
    - Para criar e deixar o banco de dados organizado.
1. [project-structure]()
    - Criada por mim para organizar os diretorios do projeto.
1. [commit-messages](https://github.com/TheDecipherist/claude-code-mastery/blob/main/skills/commit-messages/SKILL.md)
    - Para fornecer mensagens de commits com um padrão inteligente e que proporcionam informações do que foi feito naquele commit.
1. [env-secrets-manager](https://github.com/alirezarezvani/claude-skills/blob/main/engineering/skills/env-secrets-manager/SKILL.md)
    - Manter variáveis de ambiente e segredos (chaves de API, senhas de banco, tokens) seguros, do desenvolvimento local até a produção.
